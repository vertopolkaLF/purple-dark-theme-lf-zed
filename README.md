# Purple Dark Theme

An elegant dark theme for Zed with an emphasis on purple shades.

![Dark Theme Screenshot 1](./screenshots/dark-1.png)

## Features

- Carefully selected color palette
- Support for semantic syntax highlighting
- Optimized for long coding sessions
- Support for popular programming languages

## Installation

### Local dev install

1. Open Zed.
2. Run `zed: install dev extension`.
3. Select the folder
4. Run `theme selector: toggle` and choose `Purple Dark`
